# Arduino-Hand-waver
An Arduino project that uses an HC-SR04 ultrasonic distance sensor to detect when someone gets close. Once some is detected within 20 cm and confirmed by 3 measurements an SG90 servo motor moves a cardboard hand to create a waving motion.
## Components 
Arduino, sg90 servo motor, breadboard , Hc-SR04 sensor, and some cardboard 
### Future improvements 
Prevent repeated detections by making it wait until the hand moves away before allowing another wave.
